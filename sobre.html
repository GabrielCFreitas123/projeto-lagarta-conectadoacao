Por que este projeto é extensionista?

O projeto transforma conhecimentos de desenvolvimento web em uma solução útil para a comunidade.

A proposta é facilitar o acesso a informações sobre doações e incentivar a participação social.

Como o código será publicado no GitHub, outras pessoas poderão estudar, adaptar e melhorar a solução.
